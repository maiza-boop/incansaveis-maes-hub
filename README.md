# Mães Conectadas

Crie uma página web responsiva e profissional para funcionar como a página de LINK DA BIO da marca “Incansáveis Mães”.

IMPORTANTE:

Esta página será acessada principalmente pelo Instagram e celular, portanto a experiência mobile deve ser prioridade absoluta.

A página deve funcionar como uma vitrine organizada de conteúdos, soluções e produtos voltados para mães, crianças e famílias.

A estrutura precisa ser preparada para crescer. NÃO criar uma página limitada aos produtos atuais. Novos produtos deverão poder ser adicionados futuramente dentro das categorias existentes sem necessidade de alterar a estrutura principal da página.

==================================================

1. IDENTIDADE DA MARCA

==================================================

Nome da marca:

INCANSÁVEIS MÃES

Posicionamento:

Uma marca acolhedora voltada para maternidade, filhos, família e fé, oferecendo conteúdos, ideias, atividades e soluções para diferentes momentos da vida das mães e das crianças.

A comunicação deve transmitir:

- acolhimento

- confiança

- leveza

- carinho

- praticidade

- feminilidade

- família

- maternidade real

- fé de forma delicada

Não utilizar uma comunicação infantilizada para a marca como um todo.

A marca deve parecer profissional, elegante e acolhedora.

==================================================

2. PALETA DE CORES

==================================================

Utilizar rigorosamente esta paleta:

VERDE SÁLVIA:

#A8B9A5

CREME:

#F7F1E8

ROSA QUEIMADO:

#D9A6A6

BEGE/DOURADO:

#C9A77B

MARROM ESCURO:

#493F3A

O fundo principal deve ser predominantemente CREME.

Utilizar o verde sálvia como cor principal para botões, títulos secundários e elementos de destaque.

Utilizar rosa queimado em detalhes, cartões e elementos de apoio.

Utilizar dourado/bege apenas em detalhes sutis.

Utilizar marrom escuro para textos que precisam de maior contraste.

Não utilizar cores neon, azul forte, roxo, vermelho vivo ou combinações que fujam da identidade.

==================================================

3. TIPOGRAFIA

==================================================

Utilizar uma tipografia elegante semelhante a:

Playfair Display

para títulos e elementos de destaque.

Utilizar uma tipografia semelhante a:

Montserrat

para textos, descrições e botões.

A combinação deve transmitir elegância + modernidade + excelente legibilidade.

==================================================

4. ESTILO VISUAL

==================================================

Criar um design:

- clean

- sofisticado

- feminino

- acolhedor

- moderno

- leve

- elegante

- com inspiração botânica

Utilizar:

- folhas delicadas

- pequenas linhas orgânicas

- pequenos corações

- formas arredondadas

- cantos suaves

- sombras muito discretas

- detalhes dourados finos

- bastante espaço em branco

Evitar excesso de elementos decorativos.

A página não deve parecer uma loja virtual tradicional.

Ela deve parecer uma “vitrine editorial” elegante da marca.

Maternidade • Filhos • Família • Fé

Abaixo, inserir uma frase curta:

“Conteúdos, ideias e soluções para deixar a maternidade mais leve. 💚”

📖 CRISTÃO

🤰 GESTAÇÃO & BEBÊS

Cada cartão deve possuir:

- ícone

- pequena descrição

- botão “VER OPÇÕES”

As categorias devem ser clicáveis.

10. FUNCIONAMENTO DAS CATEGORIAS

==================================================

Ao clicar em uma categoria, abrir uma seção/página mostrando os produtos daquela categoria.

Criar estrutura reutilizável.

Exemplo:

CRISTÃO

Título:

“Cristão 📖”

Texto:

“Encontre materiais para tornar momentos de aprendizado e fé mais leves e especiais.”

Depois apresentar os produtos em cards.

Cada card deve possuir:

- imagem do produto

- nome

- descrição curta

- botão

O botão deve dizer:

“QUERO CONHECER”

O botão deve ser configurável para receber futuramente o link real de cada produto.

Não inventar links.

Não inventar preços.

Não inventar depoimentos.

Não inventar avaliações.

“✨ MAIS ACESSADOS”

22. OBJETIVO FINAL

==================================================

O objetivo da página é funcionar como uma central oficial do link da bio do Instagram do:

INCANSÁVEIS MÃES

Instagram

↓

Link da bio

↓

INCANSÁVEIS MÃES

↓

↓

↓

“QUERO CONHECER”

↓
